다운로드

설치는 1분이면 끝나요. 바탕화면·시작메뉴 바로가기 자동 생성부터 새 버전 업데이트까지 알아서 챙겨드려요.

Wobi 설치하기
  • 1하단(혹은 우측 상단)에 경고 뜨면 "⋮" 클릭 → "유지"
  • 2그래도 경고가 남아있으면 화살표(⌄) 클릭 → "유지"를 한 번 더 선택
  • 3받은 설치 파일 실행
  • 4파란 화면 뜨면 "추가 정보" → "실행" 클릭
  • 5설치 마법사에서 "다음" → "설치" 클릭 (바탕화면·시작메뉴 바로가기 자동 생성)
  • 6설치 끝나면 자동 실행 — 우측 상단 위젯 버튼으로 원하는 거 추가

1인 개발자가 만든 무료 앱이라 아직 마이크로소프트 인증서가 없어서 뜨는 경고예요. 바이러스가 아니니 안심하고 진행하셔도 돼요.

"추가 정보" 링크도 없이 그냥 차단되고 끝난다면 윈도우11의 스마트 앱 제어 기능 때문이에요. Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 제어에서 껐다가 설치 파일을 다시 실행해주세요.

예전에 쓰시던 분이라면 새로 설치해도 첫 실행 튜토리얼이 안 뜰 수 있어요 — 기존에 저장해둔 위젯 배치·설정을 그대로 유지하기 위해, 저장된 데이터가 있으면 자동으로 건너뛰도록 되어있어서 그래요(정상입니다). 다시 보고 싶으면 우측 상단 설정 → "첫 실행 안내 다시보기"를 눌러주세요.
